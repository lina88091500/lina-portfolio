About

從美編，到把版面真的做出來

過去八年我負責「把東西做得好看」；現在我想把同一件事做到底 —— 從構圖、配色，一路做到能在瀏覽器裡運作的頁面。

我擅長的

版面規劃與配色、切版還原、把一長串內容整理成好讀的資訊層次。這些是我在做圖文與月會簡報時累積下來的。

我正在補強的

JavaScript 的互動邏輯，以及 PHP 的後端資料流。作品 B 與 C 就是為了練這兩塊而做的。

我的做事方式

先想清楚這個頁面要解決什麼問題再動手。我把 AI 當成加速工具：讓它產出程式碼與文案的初稿，我負責決定版面與流程、實際測試、找出問題再修到能用。從上一份工作開始就是這樣做事的。

這個作品集網站本身

版面與內容由我規劃，程式碼以 AI 工具輔助產生，再由我調整與測試。

設計

單一重點色（灰調玫瑰 #9c5c68）搭暖米白底，呼應兩組作品的粉與香檳金；標題用思源宋體、內文用思源黑體。

結構

用 hash 路由做成分頁式切換，不必整頁重新載入。六個分頁＋四個專案細節頁，看的人不用一直往下捲。

技術與分工

純 HTML / CSS / 原生 JavaScript，沒有用框架；CSS Grid ＋ Flexbox 排版。程式碼由 AI 工具協助產生，配色、版面、文案與各裝置下的測試修改則是我自己完成的。
